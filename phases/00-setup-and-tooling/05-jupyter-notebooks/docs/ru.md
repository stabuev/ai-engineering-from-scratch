# Jupyter Notebooks

> Ноутбуки — это лабораторный стол AI-инженера. Здесь вы прототипируете идеи, а затем переносите рабочий код в продакшн.

**Тип:** Практика  
**Языки:** Python  
**Предварительные требования:** Фаза 0, Урок 01  
**Время:** ~30 минут

## Цели обучения

- Установить и запустить JupyterLab, Jupyter Notebook или VS Code с расширением Jupyter
- Использовать magic-команды (`%timeit`, `%%time`, `%matplotlib inline`) для бенчмаркинга и визуализации
- Понимать, когда использовать ноутбуки, а когда скрипты
- Избегать типичных проблем: скрытого состояния, запуска ячеек вне порядка и утечек памяти

## Проблема

Практически все AI-статьи, туториалы и соревнования Kaggle используют Jupyter notebooks. Они позволяют запускать код по частям, видеть результаты прямо внутри документа, комбинировать код и пояснения и быстро экспериментировать.

Но у ноутбуков есть и серьёзные ловушки. Люди используют их даже там, где они плохо подходят. Понимание того, когда нужен notebook, а когда обычный скрипт, избавит вас от множества проблем в будущем.

## Концепция

Ноутбук состоит из ячеек. Каждая ячейка содержит либо код, либо текст.

Ядро (kernel) — это отдельный Python-процесс, работающий в фоне. Все ячейки используют одно и то же ядро, поэтому переменные сохраняются между запусками.

## Практика

### Шаг 1: выберите интерфейс

| Интерфейс | Установка | Подходит для |
|-----------|-----------|---------------|
| JupyterLab | `pip install jupyterlab` | Полноценный IDE-подход |
| Jupyter Notebook | `pip install notebook` | Минималистичный режим |
| VS Code | Расширение Jupyter | Интеграция с редактором |

```bash
pip install jupyterlab
jupyter lab
```

### Шаг 2: горячие клавиши

| Клавиша | Действие |
|---------|-----------|
| `Shift+Enter` | Выполнить ячейку |
| `A` | Вставить ячейку выше |
| `B` | Вставить ячейку ниже |
| `DD` | Удалить ячейку |

### Шаг 3: типы ячеек

**Code cells** выполняют Python-код и выводят результат.

**Markdown cells** отображают форматированный текст: заголовки, списки, формулы LaTeX, таблицы и изображения.

### Шаг 4: magic-команды

```python
%timeit np.random.randn(10000)
```

```python
%%time
model.fit(X_train, y_train, epochs=10)
```

```python
%matplotlib inline
```

### Шаг 5: вывод данных

```python
import pandas as pd

df = pd.DataFrame({
    "model": ["Linear", "Random Forest", "Neural Net"],
    "accuracy": [0.72, 0.89, 0.94]
})

df
```

Ноутбуки автоматически отображают таблицы и графики в HTML-формате.

### Шаг 6: Google Colab

Google Colab — это бесплатный облачный Jupyter notebook с GPU и предустановленными библиотеками.

1. Перейдите на https://colab.research.google.com
2. Загрузите `.ipynb`
3. Runtime → Change runtime type → T4 GPU

## Когда использовать ноутбуки, а когда скрипты

| Ноутбуки | Скрипты |
|-----------|----------|
| Исследование данных | Продакшн-код |
| Быстрые эксперименты | Пайплайны обучения |
| Визуализация | Библиотеки и пакеты |
| Объяснение результатов | Автоматические задачи |

Главное правило: **исследуйте в notebooks, поставляйте в scripts**.

## Типичные ловушки

- Запуск ячеек вне порядка
- Скрытое состояние переменных
- Утечки памяти при работе с большими датасетами

## Упражнения

1. Сравните `%timeit` для list comprehension и NumPy
2. Создайте notebook с markdown и code ячейками
3. Запустите notebook в Google Colab с бесплатным GPU

## Ключевые термины

| Термин | Что это означает |
|------|----------------|
| Kernel | Python-процесс, выполняющий код |
| Cell | Независимая ячейка notebook |
| Magic command | Специальная команда Jupyter |
| `.ipynb` | Формат notebook-файла |
