# Глоссарий AI-инженера

## A

### Agent (агент)
- **Что говорят:** «Автономный ИИ, который сам думает и действует»
- **Что это на самом деле:** Цикл while, в котором LLM решает, какой инструмент вызвать следующим, выполняет его, видит результат и повторяет

### Attention (внимание)
- **Что говорят:** «Как ИИ фокусируется на важных частях»
- **Что это на самом деле:** Механизм, где каждый токен вычисляет взвешенную сумму значений всех остальных токенов, а веса определяются их релевантностью (через скалярное произведение векторов query и key)

### Alignment (согласование)
- **Что говорят:** «Сделать ИИ безопасным»
- **Что это на самом деле:** Техническая задача привести поведение ИИ-системы в соответствие с намерениями, ценностями и предпочтениями человека, включая пограничные случаи, которые разработчик не предусмотрел

### Autoregressive (авторегрессионный)
- **Что говорят:** «ИИ генерирует по одному слову за раз»
- **Что это на самом деле:** Модель, которая предсказывает следующий токен на основе всех предыдущих, а затем подаёт своё предсказание обратно на вход для следующего шага. GPT, LLaMA и Claude — все авторегрессионные.

### Activation Function (функция активации)
- **Что говорят:** «Та нелинейная штука между слоями»
- **Что это на самом деле:** Функция, применяемая после каждого линейного слоя, чтобы ввести нелинейность. Без неё стек из любого числа линейных слоёв схлопывается в одно линейное преобразование. ReLU, GELU и SiLU — самые распространённые. Выбор напрямую влияет на то, текут ли градиенты при обучении.

### Adam (оптимизатор Adam)
- **Что говорят:** «Оптимизатор по умолчанию»
- **Что это на самом деле:** Adaptive Moment Estimation. Сочетает моментум (первый момент) с адаптивной скоростью обучения для каждого параметра (второй момент). Имеет коррекцию смещения для первых шагов. Хорошо работает на большинстве задач без тонкой настройки.

### AdamW (оптимизатор AdamW)
- **Что говорят:** «Adam, но лучше»
- **Что это на самом деле:** Adam с развязанным затуханием весов. В обычном Adam L2-регуляризация масштабируется адаптивной скоростью обучения для каждого параметра, а это не то, что нужно. AdamW применяет затухание весов напрямую к весам, независимо от статистики градиентов. Оптимизатор по умолчанию для обучения трансформеров.

### Autograd (автоматическое дифференцирование)
- **Что говорят:** «Автоматические градиенты»
- **Что это на самом деле:** Система, которая записывает операции над тензорами и автоматически вычисляет градиенты через дифференцирование в обратном режиме. Autograd в PyTorch строит граф вычислений на лету (динамический граф), а JAX использует преобразования функций (grad). Именно это делает обратное распространение практичным — вы пишете прямой проход, а фреймворк вычисляет все производные.

## B

### Batch Size (размер батча)
- **Что говорят:** «Сколько примеров за раз»
- **Что это на самом деле:** Число обучающих примеров, обрабатываемых за один прямой/обратный проход перед обновлением весов. Большие батчи дают более стабильную оценку градиента, но требуют больше памяти. Типичные значения: 32–512 при обучении, больше — при инференсе. Размер батча связан со скоростью обучения — удвоили батч, удвойте LR (правило линейного масштабирования).

### Backpropagation (обратное распространение ошибки)
- **Что говорят:** «Как нейросети учатся»
- **Что это на самом деле:** Алгоритм, который вычисляет вклад каждого веса в ошибку, применяя правило цепочки в обратном направлении по сети, а затем корректирует веса пропорционально

## C

### Context Window (контекстное окно)
- **Что говорят:** «Сколько ИИ может запомнить»
- **Что это на самом деле:** Максимальное число токенов (вход + выход), помещающихся в один вызов API. Это не память — это буфер фиксированного размера, который сбрасывается при каждом вызове

### Chain of Thought (цепочка рассуждений, CoT)
- **Что говорят:** «Заставить ИИ думать пошагово»
- **Что это на самом деле:** Приём промптинга, при котором вы просите модель показать шаги рассуждения; это повышает точность на многошаговых задачах, потому что каждый шаг обусловливает генерацию следующего токена

### CNN (свёрточная нейросеть)
- **Что говорят:** «ИИ для картинок»
- **Что это на самом деле:** Нейросеть, использующая операции свёртки (скользящие фильтры по входу) для обнаружения локальных паттернов. Стек свёрток обнаруживает всё более сложные признаки: границы, текстуры, объекты.

### CUDA (вычисления на GPU)
- **Что говорят:** «Программирование под GPU»
- **Что это на самом деле:** Платформа параллельных вычислений NVIDIA. Позволяет выполнять матричные операции на тысячах ядер GPU одновременно. PyTorch и TensorFlow используют CUDA под капотом.

### Chunking (разбиение на фрагменты)
- **Что говорят:** «Резать документы на кусочки»
- **Что это на самом деле:** Разбиение текста на сегменты перед построением эмбеддингов для поиска. Размер фрагмента задаёт гранулярность результатов поиска. Слишком мелко — теряется контекст. Слишком крупно — размывается релевантность. Частые стратегии: фиксированный размер с перекрытием, по предложениям или семантическое разбиение. Типичный размер: 256–512 токенов с перекрытием 10–20%.

### Contrastive Learning (контрастивное обучение)
- **Что говорят:** «Обучение через сравнение»
- **Что это на самом деле:** Обучение, при котором похожие пары притягиваются, а непохожие — отталкиваются в пространстве эмбеддингов. CLIP использует это: совпадающие пары изображение-текст против несовпадающих.

### Cosine Similarity (косинусное сходство)
- **Что говорят:** «Насколько похожи два вектора»
- **Что это на самом деле:** Косинус угла между двумя векторами: dot(a, b) / (||a|| * ||b||). Диапазон от -1 (противоположны) до 1 (одинаковое направление). Игнорирует длину, важно только направление. Стандартная метрика сходства для эмбеддингов и семантического поиска.

### Cross-Entropy (перекрёстная энтропия)
- **Что говорят:** «Функция потерь для классификации»
- **Что это на самом деле:** Измеряет расхождение между двумя вероятностными распределениями. Для классификации: -sum(y_true * log(y_pred)). Для языковых моделей: отрицательный логарифм вероятности правильного следующего токена. Меньше — лучше. Перплексия — это просто exp(перекрёстной энтропии).

## D

### Data Augmentation (аугментация данных)
- **Что говорят:** «Наделать больше обучающих данных»
- **Что это на самом деле:** Создание изменённых копий существующих данных (повернуть изображения, добавить шум, перефразировать текст) для увеличения разнообразия обучающей выборки без сбора новых данных. Снижает переобучение.

### Decoder (декодер)
- **Что говорят:** «Часть, отвечающая за выход»
- **Что это на самом деле:** В трансформерах декодер использует каузальное (маскированное) само-внимание, чтобы каждая позиция могла обращаться только к более ранним позициям. GPT — только декодер. BERT — только энкодер. T5 — энкодер-декодер.

### Diffusion Model (диффузионная модель)
- **Что говорят:** «ИИ, который генерирует картинки из шума»
- **Что это на самом деле:** Модель, обученная обращать постепенный процесс зашумления — она учится предсказывать и убирать шум, а при генерации стартует из чистого шума и итеративно его удаляет

### DPO (прямая оптимизация предпочтений)
- **Что говорят:** «Упрощённый RLHF»
- **Что это на самом деле:** Метод обучения, полностью пропускающий модель вознаграждения — он напрямую оптимизирует языковую модель, чтобы она предпочитала лучший ответ в парах человеческих предпочтений

### Dropout (дропаут)
- **Что говорят:** «Случайно выключать нейроны»
- **Что это на самом деле:** При обучении случайно обнуляется часть активаций. Это заставляет сеть не полагаться на какой-то один нейрон. При инференсе отключается. Простая, но эффективная регуляризация.

## E

### Eigenvalue (собственное значение)
- **Что говорят:** «Какая-то математика для PCA»
- **Что это на самом деле:** Для матрицы A собственное значение lambda удовлетворяет Av = lambda*v для некоторого вектора v. Оно показывает, насколько матрица масштабирует векторы в этом направлении. Большие собственные значения — направления высокой дисперсии в ваших данных.

### Embedding (эмбеддинг)
- **Что говорят:** «Какая-то магия ИИ, превращающая слова в числа»
- **Что это на самом деле:** Обученное отображение дискретных объектов (слов, изображений, пользователей) в плотные векторы в непрерывном пространстве, где похожие объекты оказываются рядом

### Encoder (энкодер)
- **Что говорят:** «Часть, отвечающая за вход»
- **Что это на самом деле:** В трансформерах энкодер использует двунаправленное само-внимание, чтобы каждая позиция могла обращаться ко всем позициям. BERT — только энкодер. Хорош для задач понимания (классификация, NER), но не для генерации.

### Epoch (эпоха)
- **Что говорят:** «Один проход по данным»
- **Что это на самом деле:** Ровно это. Один полный проход по каждому примеру обучающей выборки. Несколько эпох — данные просматриваются несколько раз. Больше эпох может улучшить обучение, но повышает риск переобучения.

## F

### Feature (признак)
- **Что говорят:** «Столбец в ваших данных»
- **Что это на самом деле:** Отдельное измеримое свойство данных. В классическом ML признаки конструируют вручную. В глубоком обучении сеть учит признаки автоматически из сырых данных.

### Few-Shot (few-shot, обучение на нескольких примерах)
- **Что говорят:** «Сначала дай ИИ пару примеров»
- **Что это на самом деле:** Включение небольшого числа пар вход-выход в промпт перед тем, как попросить модель выполнить задачу. Обычно 3–5 примеров. Модель подхватывает паттерн из этих примеров, чтобы понять нужный формат и поведение. Противопоставляется zero-shot (без примеров) и дообучению (тысячи примеров, зашитых в веса).

### Fine-tuning (дообучение)
- **Что говорят:** «Обучить ИИ на своих данных»
- **Что это на самом деле:** Начать с весов предобученной модели и продолжить обучение на меньшем, специфичном для задачи наборе данных. Обновляет только существующие веса, не добавляет новых знаний с нуля

### Function Calling (вызов функций)
- **Что говорят:** «ИИ, который умеет пользоваться инструментами»
- **Что это на самом деле:** Структурированный способ для LLM запрашивать выполнение внешних функций. Вы описываете инструменты через JSON Schema, модель выдаёт структурированный JSON-объект с указанием, какую функцию вызвать и с какими аргументами, ваш код выполняет её, а результат возвращается модели. Не то же самое, что агенты — вызов функций это механизм, агенты это цикл.

## G

### Guardrails (защитные ограничения)
- **Что говорят:** «Фильтры безопасности для ИИ»
- **Что это на самом деле:** Слои валидации входа/выхода вокруг LLM, которые обнаруживают и блокируют вредный контент, попытки инъекции в промпт, утечку персональных данных или ответы не по теме. Обычно это пайплайн: фильтр входа -> LLM -> фильтр выхода. Может быть на правилах (regex, списки ключевых слов) или на модели (классификатор, оценивающий безопасность).

### GPT (GPT)
- **Что говорят:** «ChatGPT» или «тот самый ИИ»
- **Что это на самом деле:** Generative Pre-trained Transformer — конкретная архитектура, предсказывающая следующий токен с помощью декодерного трансформера, обученного на больших текстовых корпусах

### GAN (генеративно-состязательная сеть)
- **Что говорят:** «Два ИИ дерутся друг с другом»
- **Что это на самом деле:** Сеть-генератор пытается создать реалистичные данные, а сеть-дискриминатор — отличить настоящее от поддельного. Они обучаются вместе: генератор всё лучше обманывает дискриминатора, а дискриминатор всё лучше выявляет подделки.

### Gradient (градиент)
- **Что говорят:** «Наклон»
- **Что это на самом деле:** Вектор частных производных, указывающий в направлении наискорейшего роста. В ML вы движетесь против градиента (градиентный спуск), чтобы минимизировать потери.

### Gradient Descent (градиентный спуск)
- **Что говорят:** «Как ИИ улучшается»
- **Что это на самом деле:** Алгоритм оптимизации, который корректирует параметры в направлении наибольшего снижения функции потерь, как спуск с горы в многомерном ландшафте

## H

### Hyperparameter (гиперпараметр)
- **Что говорят:** «Настройки, которые ты крутишь»
- **Что это на самом деле:** Значения, задаваемые до обучения и управляющие самим процессом обучения: скорость обучения, размер батча, число слоёв, доля дропаута. В отличие от параметров модели (весов), они не выучиваются из данных.

### Hallucination (галлюцинация)
- **Что говорят:** «ИИ врёт» или «выдумывает»
- **Что это на самом деле:** Модель генерирует правдоподобно звучащий текст, не опирающийся на обучающие данные или заданный контекст — она достраивает паттерн, а не извлекает факт

## I

### Inference (инференс)
- **Что говорят:** «Запуск ИИ»
- **Что это на самом деле:** Использование обученной модели для предсказаний на новых данных. Обновления весов не происходит. Это то, что вы делаете в продакшене: подали вход, получили выход.

### Inductive Bias (индуктивное смещение)
- **Что говорят:** Никогда о таком не слышали
- **Что это на самом деле:** Допущения, встроенные в архитектуру модели. CNN предполагают, что важны локальные паттерны (свёртка). RNN предполагают, что важен порядок (последовательная обработка). Трансформеры предполагают, что всё может быть связано со всем (внимание). Правильное смещение помогает модели учиться быстрее и на меньших данных.

### JAX (JAX)
- **Что говорят:** «ML-фреймворк от Google»
- **Что это на самом деле:** Совместимая с NumPy библиотека, добавляющая автоматическое дифференцирование (grad), JIT-компиляцию (jit), автоматическую векторизацию (vmap) и параллелизм по устройствам (pmap). В отличие от объектно-ориентированного стиля PyTorch, JAX чисто функционален — никакого скрытого состояния, никаких мутаций на месте. Используется Google DeepMind для AlphaFold, Gemini и крупномасштабных исследований.

## K

### KV Cache (KV-кеш, кеш ключей и значений)
- **Что говорят:** «Ускоряет инференс»
- **Что это на самом деле:** При авторегрессионной генерации кеширование матриц key и value от предыдущих токенов, чтобы не пересчитывать их на каждом шаге. Меняет память на скорость. Необходим для быстрого инференса LLM.

## L

### Latent Space (латентное пространство)
- **Что говорят:** «Скрытое представление»
- **Что это на самом деле:** Сжатое, обученное пространство представлений, где похожие входы отображаются в близкие точки. Автоэнкодеры, VAE и диффузионные модели все работают в латентном пространстве. Оно меньшей размерности, чем вход, но улавливает важную структуру.

### Learning Rate (скорость обучения)
- **Что говорят:** «Как быстро ИИ учится»
- **Что это на самом деле:** Скаляр, управляющий размером шага при градиентном спуске. Слишком высокая — перескакивает минимум и расходится. Слишком низкая — сходится слишком медленно или застревает. Самый важный гиперпараметр.

### LLM (большая языковая модель)
- **Что говорят:** «ИИ» или «мозг»
- **Что это на самом деле:** Нейросеть на основе трансформера, обученная предсказывать следующий токен в последовательности, с миллиардами параметров, обученная на текстовых данных интернет-масштаба

### LoRA (низкоранговая адаптация)
- **Что говорят:** «Эффективное дообучение»
- **Что это на самом деле:** Вместо обновления всех весов вставляются небольшие низкоранговые матрицы рядом с исходными весами. Обучаются только эти маленькие матрицы, что сокращает память в 10–100 раз

### Loss Function (функция потерь)
- **Что говорят:** «Насколько ИИ ошибается»
- **Что это на самом деле:** Функция, измеряющая разрыв между предсказанным и фактическим выходом. Обучение минимизирует её. MSE для регрессии, перекрёстная энтропия для классификации, контрастивная потеря для эмбеддингов. Выбор функции потерь определяет, что для модели значит «хорошо».

## M

### Mixed Precision (смешанная точность)
- **Что говорят:** «Трюк для ускорения обучения»
- **Что это на самом деле:** Использование float16 для прямого прохода и большинства операций (быстрее, меньше памяти), но сохранение float32 для накопления градиентов и обновления весов (точнее). Даёт ускорение в 2 раза при пренебрежимо малой потере точности.

### MoE (смесь экспертов)
- **Что говорят:** «Работает только часть модели»
- **Что это на самом деле:** Модель со множеством «экспертных» подсетей, где механизм маршрутизации отправляет каждый вход лишь к нескольким экспертам. Полная модель огромна, но каждый прямой проход дёшев, потому что большинство экспертов пропускается. Mixtral и GPT-4 используют это.

### MCP (Model Context Protocol)
- **Что говорят:** «Способ для ИИ пользоваться инструментами»
- **Что это на самом деле:** Открытый протокол (JSON-RPC поверх stdio/HTTP), стандартизирующий, как ИИ-приложения подключаются к внешним источникам данных и инструментам, с типизированными схемами для инструментов, ресурсов и промптов

## N

### NaN (не число)
- **Что говорят:** «Обучение упало»
- **Что это на самом деле:** Значение с плавающей точкой, обозначающее неопределённый результат (0/0, inf-inf). При обучении NaN в потерях обычно означает: слишком высокую скорость обучения, взрыв градиентов, логарифм нуля или деление на ноль. Всегда первое, что стоит проверить, когда обучение ломается.

### Normalization (нормализация)
- **Что говорят:** «Масштабирование данных»
- **Что это на самом деле:** Приведение значений к стандартному диапазону. Batch normalization нормализует по батчу. Layer normalization нормализует по признакам. Обе стабилизируют обучение и позволяют использовать более высокие скорости обучения.

## O

### Overfitting (переобучение)
- **Что говорят:** «Модель запомнила данные»
- **Что это на самом деле:** Модель хорошо работает на обучающих данных, но плохо на невиданных. Она выучила шум, а не сигнал. Лечится: больше данных, регуляризация (дропаут, затухание весов), ранняя остановка, аугментация данных, более простая модель.

### Optimizer (оптимизатор)
- **Что говорят:** «Штука, которая обновляет веса»
- **Что это на самом деле:** Алгоритм, использующий градиенты для обновления параметров модели. SGD — самый простой. Adam — самый распространённый. У каждого оптимизатора свои свойства: скорость сходимости, расход памяти, чувствительность к гиперпараметрам.

## P

### Parameter (параметр)
- **Что говорят:** «Размер модели»
- **Что это на самом деле:** Обучаемое значение в модели, обычно вес или смещение. «7B параметров» означает 7 миллиардов обучаемых чисел. Каждый параметр float32 занимает 4 байта, так что 7B параметров = 28 ГБ памяти только на веса.

### Perplexity (перплексия)
- **Что говорят:** «Насколько модель растеряна»
- **Что это на самом деле:** Экспонента средней перекрёстной энтропии. Меньше — лучше. Перплексия 10 означает, что модель настолько же неуверена, как если бы выбирала равномерно из 10 токенов на каждом шаге.

### Precision & Recall (точность и полнота)
- **Что говорят:** «Метрики качества»
- **Что это на самом деле:** Precision (точность) = из помеченных объектов сколько оказались верными. Recall (полнота) = из всех верных объектов сколько вы нашли. Они компромиссны: поймать каждое спам-письмо (высокая полнота) значит больше ложных срабатываний (низкая точность). F1-мера — их среднее гармоническое. Точность важна, когда дороги ложноположительные, полнота — когда дороги ложноотрицательные.

### Prompt Engineering (проектирование промптов)
- **Что говорят:** «Правильно разговаривать с ИИ»
- **Что это на самом деле:** Проектирование входного текста для надёжного получения нужных выходов — включая системные промпты, few-shot примеры, инструкции по формату и триггеры цепочки рассуждений

### Prompt Injection (инъекция в промпт)
- **Что говорят:** «Взлом ИИ словами»
- **Что это на самом деле:** Атака, при которой вредоносный текст во входе перекрывает системный промпт или инструкции. Прямая инъекция: пользователь пишет «Игнорируй предыдущие инструкции». Косвенная инъекция: извлечённый документ содержит скрытые инструкции. Аналог SQL-инъекции для LLM. Полного решения нет — защита это слои валидации входа, фильтрации выхода и разделения привилегий.

## Q

### QLoRA (квантованная LoRA)
- **Что говорят:** «LoRA, но дешевле»
- **Что это на самом деле:** Quantized LoRA. Держит замороженные веса базовой модели в 4-битной точности (формат NF4), обучая LoRA-адаптеры в 16 битах. Сокращает память ещё в 3–4 раза по сравнению с обычной LoRA. Модель 7B, которой нужно 14 ГБ с LoRA, помещается в 4–6 ГБ с QLoRA. Качество в пределах 1% от полного дообучения на большинстве бенчмарков.

## R

### RAG (генерация с дополненным поиском)
- **Что говорят:** «ИИ, который умеет искать»
- **Что это на самом деле:** Паттерн, при котором вы извлекаете релевантные документы из базы знаний (по сходству эмбеддингов), вставляете их в промпт и позволяете LLM ответить на основе этого контекста

### RLHF (обучение с подкреплением на обратной связи от человека)
- **Что говорят:** «Как делают ИИ полезным»
- **Что это на самом деле:** Пайплайн обучения: (1) собрать человеческие предпочтения по выходам модели, (2) обучить модель вознаграждения на этих предпочтениях, (3) использовать PPO, чтобы оптимизировать LLM выдавать выходы с более высоким вознаграждением

### Quantization (квантизация)
- **Что говорят:** «Сделать модель меньше»
- **Что это на самом деле:** Снижение точности весов модели с float32 (4 байта) до int8 (1 байт) или int4 (0,5 байта). Меняет небольшую долю точности на 4–8-кратное снижение памяти и более быстрый инференс. GPTQ, AWQ и GGUF — распространённые форматы.

### ReLU (ReLU)
- **Что говорят:** «Функция активации»
- **Что это на самом деле:** Rectified Linear Unit: f(x) = max(0, x). Простейшая нелинейная активация. Быстро вычисляется, не насыщается для положительных значений. Используется повсюду, потому что работает и дёшева. Варианты: LeakyReLU, GELU, SiLU.

### ROUGE (ROUGE)
- **Что говорят:** «Метрика для суммаризации»
- **Что это на самом деле:** Recall-Oriented Understudy for Gisting Evaluation. Измеряет пересечение между сгенерированным и эталонным текстом. ROUGE-1 считает совпадения униграмм, ROUGE-2 — биграмм, ROUGE-L находит наидлиннейшую общую подпоследовательность. Дёшево считается, но измеряет лишь поверхностное сходство — два предложения с одинаковым смыслом, но разными словами получают низкий балл.

## S

### Semantic Search (семантический поиск)
- **Что говорят:** «Умный поиск, понимающий смысл»
- **Что это на самом деле:** Поиск документов по смыслу, а не по совпадению ключевых слов. Эмбеддите запрос и все документы в одно векторное пространство, затем возвращаете документы, чьи эмбеддинги ближе всего к эмбеддингу запроса. «Платёж не прошёл» находит «транзакция отклонена», хотя у них нет общих слов. Работает на моделях эмбеддингов + векторных базах данных.

### Streaming (потоковая передача)
- **Что говорят:** «Ответ появляется слово за словом»
- **Что это на самом деле:** LLM отправляет токены по мере их генерации, а не ждёт полного ответа. Использует Server-Sent Events (SSE) или WebSocket. Снижает воспринимаемую задержку до первого токена с секунд до миллисекунд. Необходимо для продакшен-чатов. Каждый фрагмент содержит дельту (частичный токен или слово).

### Self-Attention (само-внимание)
- **Что говорят:** «Как модель решает, на что смотреть»
- **Что это на самом деле:** Каждый токен вычисляет векторы query, key и value. Вес внимания между двумя токенами = скалярное произведение их query и key, масштабированное и прогнанное через softmax. Выход = взвешенная сумма векторов value. Позволяет каждому токену видеть каждый другой.

### SFT (обучение с учителем на инструкциях)
- **Что говорят:** «Учим модель следовать инструкциям»
- **Что это на самом деле:** Дообучение предобученной модели на парах (инструкция, ответ). Модель учится генерировать ответ по инструкции. Именно это превращает базовую модель в чат-модель.

### Softmax (softmax)
- **Что говорят:** «Превращает числа в вероятности»
- **Что это на самом деле:** softmax(x_i) = exp(x_i) / sum(exp(x_j)). Преобразует вектор произвольных вещественных чисел в вероятностное распределение (все положительные, сумма равна 1). Используется в головах классификации, весах внимания и везде, где нужны вероятности.

### Swarm (рой)
- **Что говорят:** «Куча ИИ-агентов, работающих вместе как пчёлы»
- **Что это на самом деле:** Множество агентов, разделяющих состояние и координирующихся через обмен сообщениями, где сложное поведение возникает из простых индивидуальных правил, а не из центрального управления

## T

### System Prompt (системный промпт)
- **Что говорят:** «Инструкции для ИИ»
- **Что это на самом деле:** Особое сообщение в начале диалога, задающее поведение модели, роль и ограничения. Обрабатывается до пользовательских сообщений. В большинстве интерфейсов пользователю не виден. Определяет, что модель должна и не должна делать, её тон, предпочтения по формату и предметную область. Отличается от пользовательских промптов — системные задаёт разработчик.

### Tensor (тензор)
- **Что говорят:** «Многомерный массив»
- **Что это на самом деле:** Фундаментальная структура данных в фреймворках глубокого обучения. Тензор 0D — скаляр, 1D — вектор, 2D — матрица, 3D+ — тензор. В PyTorch и JAX тензоры отслеживают историю вычислений для автоматического дифференцирования и могут жить на CPU или GPU. Все входы, выходы, веса и градиенты нейросети — тензоры.

### Token (токен)
- **Что говорят:** «Слово»
- **Что это на самом деле:** Подсловная единица (обычно 3–4 символа в английском), выдаваемая токенизатором вроде BPE. «unbelievable» может быть 3 токена: «un» + «believ» + «able»

### Temperature (температура)
- **Что говорят:** «Настройка креативности»
- **Что это на самом деле:** Скаляр, делящий логиты перед softmax. Температура=1 по умолчанию. Выше — более плоское распределение — более случайные выходы. Ниже — более острое распределение — более детерминированные. Температура=0 это argmax (всегда самый вероятный токен).

### Transfer Learning (перенос обучения)
- **Что говорят:** «Использовать предобученную модель»
- **Что это на самом деле:** Взять модель, обученную на одной задаче, и адаптировать её к другой. Ранние слои учат общие признаки (границы, синтаксические паттерны), которые переносятся. Специфичного обучения требуют только поздние слои. Именно поэтому вы можете дообучить BERT под любую NLP-задачу.

### Transformer (трансформер)
- **Что говорят:** «Архитектура за современным ИИ»
- **Что это на самом деле:** Архитектура нейросети, обрабатывающая последовательности с помощью само-внимания (позволяя каждой позиции обращаться к любой другой) вместо рекуррентности, что даёт массовую параллелизацию

## U

### Underfitting (недообучение)
- **Что говорят:** «Модель не учится»
- **Что это на самом деле:** Модель слишком проста, чтобы уловить паттерны в данных. Потери на обучении остаются высокими. Лечится: больше параметров, больше слоёв, дольше обучение, меньше регуляризации, лучше признаки.

## V

### VAE (вариационный автоэнкодер)
- **Что говорят:** «Генеративная модель»
- **Что это на самом деле:** Автоэнкодер, который учит гладкое латентное пространство, заставляя выход энкодера следовать гауссовскому распределению. Из этого распределения можно сэмплировать и декодировать, чтобы генерировать новые данные. Трюк репараметризации делает его обучаемым через обратное распространение.

### Vector Database (векторная база данных)
- **Что говорят:** «Особая база данных для ИИ»
- **Что это на самом деле:** База данных, оптимизированная для хранения векторов (плотных массивов чисел) и быстрого приближённого поиска ближайших соседей. Ключевая операция в поиске по сходству, RAG и рекомендательных системах.

## W

### Weight (вес)
- **Что говорят:** «То, что модель выучила»
- **Что это на самом деле:** Одно число в матрице параметров модели. Линейный слой с входом 768 и выходом 3072 имеет 768*3072 = 2 359 296 весов. Обучение корректирует каждый вес, чтобы минимизировать функцию потерь.

### Weight Decay (затухание весов)
- **Что говорят:** «Регуляризация»
- **Что это на самом деле:** Добавление к функции потерь штрафа, пропорционального величине весов. Эквивалентно L2-регуляризации. Не даёт весам расти слишком большими. Типичное значение: 0,01–0,1.

## Z

### Zero-Shot (zero-shot, без примеров)
- **Что говорят:** «Обучение не нужно»
- **Что это на самом деле:** Использование модели на задаче, для которой её явно не обучали, без специфичных для задачи примеров в промпте. Модель обобщает из предобучения. Работает, потому что большие модели видели достаточно разнообразия, чтобы справляться с новыми форматами задач.
